# Fake-News-Detection-Dataset
This dataset contains news articles labeled as real or fake. It includes features such as article title, text, author, publication date, and category. The dataset is used to train and evaluate machine learning models for identifying misleading or false news content.
# Fake News Detection Dataset
## 📌 About the Dataset
The **Fake News Detection Dataset** contains news articles labeled as **Real** or **Fake**. It is designed for machine learning and natural language processing (NLP) projects that aim to identify misleading or false news content.
## 🎯 Objective
The main objective of this dataset is to help develop and evaluate machine learning models that can automatically classify news articles as real or fake.
## 📊 Dataset Features
The dataset may contain the following information:
* **Title** – Headline of the news article
* **Text** – Main content of the article
* **Author** – Author or source of the article
* **Publication Date** – Date when the article was published
* **Category** – Category or topic of the news
* **Label** – Indicates whether the news is Real or Fake
## 🏷️ Labels
| Label | Description                           |
| ----- | ------------------------------------- |
| Real  | Genuine or reliable news              |
| Fake  | False, misleading, or fabricated news |

## 🚀 Usage
1. Download or clone this repository.
2. Load the dataset using Python and Pandas.
3. Clean and preprocess the news text.
4. Split the data into training and testing sets.
5. Train a machine learning classification model.
6. Evaluate the model using suitable metrics.
7. Use the trained model to predict whether new articles are real or fake.
## ⚠️ Disclaimer
This dataset is intended for **educational, research, and machine learning purposes**. A model trained on this dataset should not be considered a definitive source for determining whether real-world news is true or false.
